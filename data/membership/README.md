# Membership manifest — the primaries-derived record set

Pipeline-derived, like `../binaries/multiples.tsv`: written by
`pnpm run build:membership` (`scripts/catalog/membership/`; `parked-ledger.tsv`
and `simbad_sourced_distances.tsv` by `build:catalog`), regenerated and diffed in CI, never hand-edited — except
the three files marked hand-curated below, which the build reads as input. Contract: [§ 3.1](/docs/catalog-driver.md#31-retiring-the-spine--the-membership-rule-measured-against-the-primaries).

```
membership-manifest.tsv  LFS. One row per admitted record: final
                         labels (hd/hd_alt/hr/hr_alt/hip/gl/flam, the spine's
                         proper), gaia_source_id with its binding class,
                         the primary attesting each cell, `term` — which
                         side of /docs/catalog-driver.md#1-the-driver-model's union admitted
                         the row — and `origin_key`, the record's lineage
                         key. 975,373 rows: 376,909 `primaries` and
                         598,464 `magnitude` at the V <= 11 floor
                         (scripts/catalog/membership/magnitude-term/README.md).
additions-ledger.tsv     LFS. The /docs/catalog-driver.md#61-record-parity ledger for everything the
                         primaries admit that the spine lacked: one row per
                         group, keyed on the same five identifier cells as
                         parked-ledger.tsv, under the
                         closed reason enum (admitted:hd_link_gap ·
                         admitted:hd_omitted · admitted:hip_omitted ·
                         admitted:cns5_census · component:<anchor>).
parked-ledger.tsv        Regular git. The /docs/catalog-driver.md#61-record-parity ledger for manifest
                         rows that build no record: no owned parallax, no V, or
                         no position. Same five identifier cells as
                         additions-ledger.tsv, under the closed reason enum
                         (refused_no_defensible_parallax · no_parallax_published
                         · no_v_magnitude · no_position). Generated by
                         build:catalog from placement lineage's park rows, not
                         by build:membership — which rows park is an output of
                         the record walk. The parity gate subtracts exactly these
                         rows and no more, so a park that is not on this list
                         fails the build rather than vanishing.
simbad_sourced_distances.tsv
                         Regular git. Not a membership decision: the records
                         whose shipped distance came from the parallax
                         cascade's SIMBAD tier, by gaia_source_id and hip,
                         which validate-simbad-sample excludes from its
                         SIMBAD check of the same field
                         (/scripts/catalog/distance/parallax/README.md).
                         It sits beside parked-ledger.tsv because both are
                         views of the record walk's placement. One row per
                         record (build-catalog/distSimbadPlx counts them); a
                         row carrying neither cell addresses no record
                         (`stellata-hooj.15`).
binding-review.tsv       Regular git. The 353 spine rows and addition
                         groups the derivation cannot settle alone or a
                         review already settled — contested · collision ·
                         unconfirmed · disposed — with every source's
                         candidate, the gate rejections, the printed V, the
                         derived candidate's G and SIMBAD cross-IDs, and the
                         source SIMBAD's HIP object names with its G and its
                         separation from the HIP's position.
                         A contested row ships its winner while it waits, so
                         being queued is a flag, not a withhold; an
                         unconfirmed one ships no source, and its SIMBAD-named
                         source stays a magnitude-term row
                         (/scripts/catalog/membership/binding/README.md#identity-outranks-a-blended-magnitude).
                         Pipeline-derived.
binding-review-dispositions.tsv
                         Regular git. Hand-curated, and AUTHORITATIVE
                         wherever it keys a record: tyc/hip/hd/gl cells, the
                         derived id the review was taken over, the id the row
                         ships (keep_source_id: the derived id, a listed
                         runner-up, an id no committed source proposes, or
                         empty), a basis from the closed enum
                         (tycho2_position · v70a_astrometry ·
                         simbad_dr2_object · gaia_photometry · pair_component
                         · shared_source) and the measured evidence. 54 rows:
                         9 take the derived id, 1 ships none (44 Boo), 44
                         another — 33 of those an id
                         only the cited basis stands behind
                         (membership.disposition.asserted). A kept value rides the manifest
                         as binding=reviewed.
spine-corrections.tsv    Regular git. Hand-curated: where review found
                         AT-HYG's MERGE DECISION wrong, which no other curated
                         file covers. Keyed on tyc/hip/hd/gl, one row per
                         correction, under `set` (rewrite one cell — `tyc`
                         only, since every other identifier is the label
                         merge's) or `fold` (this row is another's duplicate;
                         `value` names it). 2 rows. Every field is checked and
                         a fold's survivor must answer to everything the folded
                         row did (/scripts/catalog/membership/spine-corrections/README.md#correcting-a-merge-decision).
flamsteed-refusals.tsv   Regular git. Pipeline-derived. Every SIMBAD
                         `* NN Con` number the Flamsteed rule refuses on a
                         manifest star, with IV/27A's evidence
                         (/scripts/catalog/simbad/README.md#the-refused-numbers).
                         37 rows.
label-drops.tsv          Regular git. The /docs/catalog-driver.md#62-label-parity label ledger: every
                         spine Flamsteed / HD cell no primary attests, keyed
                         on the manifest row it left, under
                         flamsteed_unattested (3) · hd_unattested (1).
merge-divergence.tsv     Regular git. Pipeline-derived. Where each spine
                         row's merge decision departs from what the
                         primaries' own links derive — unlinked ·
                         pair_moves · derived_only · differs — with the
                         derived value and its witness. Its pair_moves rows
                         are the HIP moves onto another spine record the
                         pair rule applies, which parity gate (i) reads; the
                         other kinds move no manifest row and are the surface
                         the switch off the spine settles
                         (/scripts/catalog/membership/merge-derivation/README.md#the-divergence-ledger).
pair-review.tsv          Regular git. Pipeline-derived. One row per HIP of
                         a Tycho-2 pair the pair rule names no owner for:
                         the pair's entries and why
                         (/scripts/catalog/membership/merge-derivation/README.md#the-pair-review-queue).
pair-review-dispositions.tsv
                         Regular git. Hand-curated; header only today. The
                         entry each disposed HIP ships on, as the authority
                         (/scripts/catalog/membership/merge-derivation/README.md#disposing-a-queued-pair).
```

The five ledgers above that `build:membership` writes, and
`../classic-ids/label_flips.tsv`, are views of the stage's lineage
([Membership lineage](/scripts/catalog/membership/README.md#membership-lineage)):
no code writes their rows except by generating them from it.

`data/membership/*.tsv` is a blanket LFS rule, so the small files carry their
own `!filter` lines in `.gitattributes` — a review queue on LFS shows a
reviewer an oid instead of the rows. Any further small file here needs one too.

## Inputs

The frozen inherited spine (`../athyg/inherited-spine.tsv`, as the record of
AT-HYG's merge decisions, its `gaia_source_id` column read only as the diff
surface for the derived binding), the primaries the audit reads
(`../classic-ids/`, `../gliese/`, `../hipparcos/` with I/239's `hd` column,
`../tycho2/`, `../iau-wgsn/`, the two `../gaia/` cross-walks,
`../simbad/simbad_sptype.tsv`), `../simbad/simbad_tyc_hd.tsv` for the pair
rule's SIMBAD check, the `gl:` bridges of
`../sid/sameas-overrides.tsv`, the binding gates' evidence
(`../gaia/gaia_dr3_astrometry.tsv` for G,
`../hipparcos/hip_main_vmag.tsv` for printed V,
`../simbad/simbad_wds_xids.tsv` for component attribution), the post-gate
overlay `../classic-ids/classic_id_overlay.tsv`,
`../classic-ids/classic_id_overrides.tsv`,
`../classic-ids/cross_index_corrections.tsv` (which IV/27A arrives through, so
an addition's Flamsteed number carries the correction too),
`../binaries/multiples.tsv`, and
this folder's own `binding-review-dispositions.tsv`,
`pair-review-dispositions.tsv` and `spine-corrections.tsv`. Licence follows the inputs: CC-BY-SA-4.0 through the
spine.

## Consumed by

`membership-manifest.tsv` → **`scripts/catalog/build-catalog.ts`** (`readStars`
in `scripts/catalog/parse/stars-parse.ts`), as the membership term: every row
is a record unless it parks, and no other source adds one. It is also the
request set every catalog-scoped refresh pull is derived from
([Request sets are membership-derived](/scripts/refresh/README.md#request-sets-are-membership-derived)).

`scripts/catalog/membership/membership-manifest-gate.test.ts` reads all of
these — the parity gate over them against the spine, the SID bridges and the
built catalogue, including the two row-for-row joins (queue ↔ dispositions,
label drops ↔ manifest).
